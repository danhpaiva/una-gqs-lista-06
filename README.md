# 🚀 Calculadora de Tempo de Viagem para Marte (Java)

Este projeto contém um algoritmo simples em Java projetado para estimar a duração de uma viagem da Terra até Marte, considerando parâmetros de distância e velocidade média de uma missão espacial padrão.

---

## 📌 Visão Geral

A distância entre a Terra e Marte varia constantemente devido às suas órbitas ao redor do Sol. Para este projeto, utiliza-se a distância média ideal durante uma janela de lançamento (Transferência de Hohmann), que ocorre a cada 26 meses.

### Parâmetros Utilizados
* **Distância Média Ideal:** $225.000.000\text{ km}$
* **Velocidade Média da Nave:** $39.600\text{ km/h}$
